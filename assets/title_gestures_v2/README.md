# 눈에 잘 보이는 타이틀 손짓

기존 타이틀의 해골을 참조해 내장 `image_gen`으로 제작한 큰 손짓 8포즈다. 톱니를 가슴 높이에서 머리 위까지 들어 올리고 좌우로 흔든 뒤 내려놓는다. 기존 4포즈와 원본은 `title_motion_v1`에 보존한다. 배경·로고·수리공·불꽃도 기존 에셋을 사용한다.

생성 원본은 `sources/skeleton-wave.png`, 전체 프롬프트와 투명 배경 정리 기록은 `prompts.json`에 있다. `node tools/art/build-title-gestures.mjs`로 4×2 시트를 분리한다. 투명 배경·셀 여백·8포즈 고유성·해시를 검사하고 바닥 기준점을 기록한다. 포즈마다 높이를 늘려 맞추지 않고 동일한 배율로 그려 팔을 크게 드는 차이를 유지한다.
