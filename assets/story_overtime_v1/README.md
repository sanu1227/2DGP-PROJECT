# 오늘도 야근 — 8컷 프롤로그

내장 `image_gen`으로 제작한 두 장의 2×2 만화 원본이다. 각 이미지는 1448×1086이며, 왼쪽 위·오른쪽 위·왼쪽 아래·오른쪽 아래 순서로 표시한다. 기존 청록색 후드·황동 고글·가죽 작업복의 수리공과 만화 스타일을 참조했다.

- `act_01.png`: 용사의 화려한 등장, 함정과 병사 격파, 보물을 챙긴 퇴장, 터덜터덜 출근하는 수리공.
- `act_02.png`: 마왕 상사의 재촉, 수리와 병사 조립 소동, 끝나지 않는 추가 업무, 해골 병사의 문자 그대로 손 빌려주기.
- `prompts.json`: 각 그림의 전체 생성 프롬프트, 참조 이미지와 역할, 최종 파일 경로·크기·SHA-256.

생성 원본은 별도 보존하고 최종 PNG를 이 폴더에 복사했다. 그림에는 글자를 넣지 않았다. `game/story.py`에서 대사·효과음·컷 순서를 정의하고, `game/comic.py`에서 주아체 말풍선을 그린다. 하단 설명문 없이 인물 간 대화로 이야기를 전달한다. 마왕은 주인공의 상사이며, 플레이어는 용사가 떠난 뒤 던전을 수리하는 직원이다.

현재 게임은 원본을 보존한 채 `act_01`의 1·3·4번째 컷과 `act_02`의 1번째 컷을 선택해 한 장의 4컷 만화로 전개한다. `game/story.py`의 재생 상태와 `game/comic.py`의 렌더러가 컷의 등장, 시간차 말풍선, 확대·흔들림 효과를 담당한다. 기존 8컷 PNG와 생성 프롬프트는 변경하지 않았다.

캐릭터가 컷 안에서 움직이는 현재 버전은 이 원본의 인물·화풍을 참조한 `assets/comic_motion_v1`의 배경과 투명 포즈를 사용한다. 기존 두 장의 원본은 장면과 디자인 참조로 보존한다.
