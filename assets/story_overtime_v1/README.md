# 오늘도 야근 — 8컷 프롤로그

내장 `image_gen`으로 제작한 두 장의 2×2 만화 원본이다. 각 이미지는 1448×1086이며, 왼쪽 위·오른쪽 위·왼쪽 아래·오른쪽 아래 순서로 표시한다. 기존 청록색 후드·황동 고글·가죽 작업복의 수리공과 만화 스타일을 참조했다.

- `act_01.png`: 용사의 화려한 등장, 함정과 병사 격파, 보물을 챙긴 퇴장, 터덜터덜 출근하는 수리공.
- `act_02.png`: 마왕 상사의 재촉, 수리와 병사 조립 소동, 끝나지 않는 추가 업무, 해골 병사의 문자 그대로 손 빌려주기.
- `prompts.json`: 각 그림의 전체 생성 프롬프트, 참조 이미지와 역할, 최종 파일 경로·크기·SHA-256.

생성 원본은 별도 보존하고 최종 PNG를 이 폴더에 복사했다. 그림에는 글자를 넣지 않았다. `game/story.py`에서 대사·효과음·컷 순서를 정의하고, `game/front_end.py`에서 주아체 말풍선을 그린다. 하단 설명문 없이 인물 간 대화로 이야기를 전달한다. 마왕은 주인공의 상사이며, 플레이어는 용사가 떠난 뒤 던전을 수리하는 직원이다.
