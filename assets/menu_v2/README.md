# 타이틀과 스토리 카툰

내장 `image_gen`으로 제작한 게임용 원본 PNG다. 기존 수리공의 청록색 후드·황동 고글·가죽 작업복을 참조했다. 제목 글자는 타이틀 그림에 포함하고, 이야기·설명·버튼은 게임에서 한글 글꼴로 그린다.

- `title.png`: 던전 배경과 중앙 게임 로고. 하단 중앙은 실제 버튼 영역이다.
- `story.png`: 초기 2×2 이야기 그림. 현재는 뒤쪽 두 컷을 복구 목표·조작 안내에 사용한다.
- `story_comic.png`: 이전 4컷 프롤로그의 보존본이자 새 만화의 스타일 참조다. 현재 프롤로그는 [story_overtime_v1](../story_overtime_v1/README.md)의 야근 코미디 8컷을 사용한다.
- `prompts.json`: 전체 생성 프롬프트와 참조 역할.
- `story_comic_prompt.json`: 코믹한 만화의 생성 프롬프트와 참조 이미지.

첨부된 Fantasy Farm 예시는 중앙 로고와 배경의 구성만 참고했으며, 해당 이미지나 로고는 게임에 포함하지 않는다. 생성된 그림의 규칙 설명은 실제 퍼즐 모델을 기준으로 런타임 자막에서 제공한다.
