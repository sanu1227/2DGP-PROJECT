# 네 컷 만화의 독립 캐릭터 애니메이션

기존 만화의 청록색 후드·황동 고글·가죽 작업복 수리공과 용사·해골·마왕을 참조해 내장 `image_gen`으로 제작했다. 영상 모델이나 동영상 디코더 없이 PNG만 사용하는 에셋이다.

- `sources/backgrounds.png`: 네 컷의 인물을 제거한 배경. 원래 등장·퇴장·출근·마왕 장면의 구도와 화풍을 유지한다.
- `sources/worker.png`: 4×3 배열의 수리공 12포즈. 0~5 걷기, 6 멈춤, 7 들숨, 8~9 한숨, 10~11 지친 마무리.
- `sources/cast.png`: 용사 등장·퇴장, 해골 경비·부서진 병사, 마왕, 움츠린 수리공, 해골 머리, 숨 효과.
- `sprites/`: 투명 PNG 20개. 362×362 캔버스와 발 높이를 맞춘 게임용 이미지.
- `manifest.json`: 원본과 출력 SHA-256, 실제 자르기 영역, 발 기준점과 불투명 영역.
- `prompts.json`: 전체 생성 프롬프트, 참조 이미지 역할과 원본 저장 경로.

원본은 수정하지 않는다. `node tools/art/build-comic-motion.mjs`로 이미지를 분리하고 투명 여백·발 높이를 정렬한다. 수리공 포즈는 개별 높이에 맞춰 늘리지 않고 같은 픽셀 배율을 유지해 숙이는 자세가 보존된다. 생성된 용사의 검이 첫 셀 경계를 넘어가므로, 다음 캐릭터와의 실제 빈 공간에서 분리한다. 원본 셀 밖의 다른 인물이 섞이지 않는지 검사한다.

수리공은 투명 포즈 전환으로 발·얼굴·고개를 바꾸며, 화면 위치와 숨 효과는 게임 시간으로 계산한다. 나머지 인물은 독립 이미지의 위치·회전·크기 변화를 사용한다. 프레임마다 새 그림을 생성하지 않는다.
