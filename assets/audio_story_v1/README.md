# 만화 효과음

프로젝트용으로 직접 합성한 오리지널 효과음이다. 외부 녹음·음원 샘플·유료 서비스는 사용하지 않는다. 표준 라이브러리만 사용하는 `python tools/audio/build-story-sounds.py`로 재현한다.

- `hero_arrival.wav`: 1.25초의 짧은 금관 팡파르와 낮은 등장 충격음.
- `dungeon_collapse.wav`: 1.95초, 낮은 석재 충격과 짧은 파열음 뒤 크기가 다른 잔해가 연달아 굴러 떨어지는 붕괴음.
- `boss_bark.wav`: 0.82초의 낮은 목소리 형태로 합성한 코믹한 호통. 실제 대사를 읽는 음성은 아니다.
- `step_left.wav`, `step_right.wav`: 각 0.29초, 바닥을 딛는 저음과 끄는 마찰음.
- `worker_sigh.wav`: 1.2초, 낮아지는 목소리 성분과 긴 날숨.

형식은 44,100Hz·스테레오·16비트 PCM WAV다. 파일의 최대 진폭은 0.58 이하이며 시작·끝을 짧게 감쇠해 클릭음을 줄였다. `manifest.json`에 길이·최대 진폭·RMS·SHA-256을 기록한다. 재생 시 추가로 음량을 낮춰 사용한다. 시스템 음량은 변경하지 않는다.

`game/story_audio.py`가 첫 컷 0.42초에 등장음, 두 번째 컷의 화면 충격이 시작하는 0.28초에 붕괴음, 세 번째 컷의 발 접지 6회에 좌우 발소리, 3.45초에 한숨, 네 번째 컷 0.55초와 1.30초에 호통을 재생한다. 붕괴음은 해당 컷의 2.23초에 끝나며 다음 컷을 침범하지 않는다. 같은 이벤트는 한 번만 재생하며 0.2초보다 오래 지난 소리는 건너뛴다. 재생 음량은 SDL_mixer의 78/128이며 자신의 채널만 일시정지·재개·종료한다. `tools/audio/create-story-preview.py`로 실제 타이밍 또는 `--montage` 미리듣기를 오프라인 생성한다.
