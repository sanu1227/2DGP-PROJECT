# 게임 기본 글꼴

22px 이상 버튼·말풍선·제목에는 우아한형제들의 배민 주아체(Jua)를 사용한다. 둥근 붓글씨 형태로 코믹한 프롤로그와 게임 그림에 맞춘다. 13~18px 안내·HUD에는 류양희의 고운돋움(Gowun Dodum)을 사용해 작은 글자와 주아체에 없는 화살표·기호를 읽기 쉽게 표시한다. 타이틀 그림에 포함된 로고는 별도의 이미지다.

- `Jua-Regular.ttf`: Google Fonts가 배포하는 수정하지 않은 원본.
- `GowunDodum-Regular.ttf`: Google Fonts가 배포하는 수정하지 않은 원본.
- `Jua-OFL.txt`, `GowunDodum-OFL.txt`: 각 글꼴의 저작권 표시와 SIL Open Font License 1.1 전문. 글꼴과 함께 배포한다.
- `sources.json`: 원본 다운로드 URL, 날짜와 SHA-256.

출처: [Google Fonts의 Jua](https://github.com/google/fonts/tree/main/ofl/jua), [Jua 원본 프로젝트](https://github.com/googlefonts/jua), [Google Fonts의 Gowun Dodum](https://github.com/google/fonts/tree/main/ofl/gowundodum).
