# 3/4 탑다운 전용 에셋 v1

정면에 가까운 3/4 탑다운을 기본 시점으로 선택한 뒤 제작한 전용 에셋입니다. 가로축은 수평이고 바닥 깊이는 가로의 약 65%입니다. 기존 사선 에셋과 생성 원본은 별도로 보존합니다.

| 묶음 | 개수 | 내용 |
| --- | ---: | --- |
| [지형](atlases/terrain.png) | 16 | 제련소·납골당·서고·수로의 일반 바닥, 균열 바닥, 벽 윗면, 벽 앞면 |
| [장치](atlases/devices.png) | 16 | 함정 3상태, 출구 2상태, 레버 2상태, 작업대 2상태, 발판 2상태, 투입·배출구, 문 2상태, 벨트 |
| [수리공](atlases/worker.png) | 16 | 아래·위·왼쪽·오른쪽의 대기, 걷기 A/B, 운반 자세 |
| [물건과 장식](atlases/props.png) | 16 | 부품·뼈·병사 2상태, 네 방 테마의 소품 12개 |

총 64개 투명 PNG를 `sprites/`에, 1024×1024 아틀라스 4장을 `atlases/`에 저장합니다. `manifest.json`은 실제 표시 영역, 발 기준점, 아틀라스 좌표, 원본 절단 위치와 SHA-256을 기록합니다. 물체와 캐릭터의 발 기준점은 `(128,232)`, 지형 중심은 `(128,160)`입니다. 수리공은 모든 프레임에 같은 배율을 적용합니다.

## 제작과 재현

내장 `image_gen.imagegen`을 사용했습니다. 전체 프롬프트와 정확한 셀 순서는 [terrain.json](source/terrain.json), [devices.json](source/devices.json), [worker.json](source/worker.json), [props.json](source/props.json)에 보존합니다. 수리공은 기존 `assets/art_v1/characters/worker/worker_sw_idle.png`를 정체성 참조로 사용했습니다. 원본 네 장은 같은 `source/` 폴더의 PNG입니다.

```powershell
node tools/art/build-topdown.mjs
```

이 명령은 보존한 원본을 분리·정렬하여 다시 내보냅니다. 기존 `tools/art`의 sharp를 사용하며 게임 실행 의존성을 추가하지 않습니다. 실제 알파 여백에서 행·열 경계를 찾아 인접 소품이 잘리는 것을 막고, 거의 투명한 외곽 노이즈를 정리합니다. 창의적인 이미지 수정이나 재생성은 수행하지 않습니다.

## 검증

`validation.json`에 64개 출력, 투명 배경, 출력 잘림 0개, 원본 셀 경계 침범 0개를 기록했습니다. 네 아틀라스에서 방향·장치 상태·투명 여백을 육안 확인했습니다. 게임 적용과 실제 화면 검증 결과는 프로젝트 개발 기록에 별도로 남깁니다.
