# 탑다운 플레이 에셋

화면의 수평·수직 축에 맞춘 정사각 격자용 스프라이트입니다. 내장 ImageGen으로 원화 네 장을 만들고, 아틀라스 네 장에 스프라이트 64개를 담았습니다.

- 지형 16개는 여덟 방의 이동 바닥과 막힌 벽을 구분합니다.
- 장치 16개는 함정, 출구, 레버, 작업대, 발판, 연결문, 초소, 잔해의 상태를 표현합니다.
- 소품 16개는 운반물, 투입·배출구, 마력 장치, 윈치, 인부와 방 장식을 포함합니다.
- 수리공 16프레임은 네 방향마다 대기, 걷기 두 프레임, 운반 자세를 제공합니다.

거울의 반사면과 화살표는 생성한 회전대 위에 현재 반사 각도로 그립니다. [원화 프롬프트](source/prompts.json)에 각 시트의 셀 순서와 수리공 참조를 기록했습니다.

`node tools/art/build-topdown-v2.mjs`로 원화에서 아틀라스와 `manifest.json`을 다시 만들 수 있습니다. 기존 아트 제작용 Sharp 패키지를 사용합니다.
