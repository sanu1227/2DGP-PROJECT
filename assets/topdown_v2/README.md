# 탑다운 플레이 에셋

화면의 수평·수직 축에 맞춘 정사각 격자용 스프라이트입니다. 내장 ImageGen 원화를 투명 여백에서 잘라 아틀라스 19장에 스프라이트 186개를 담았습니다.

- 지형 16개는 여덟 방의 이동 바닥과 막힌 벽을 구분합니다.
- 장치 16개는 함정, 출구, 레버, 작업대, 발판, 연결문, 초소, 잔해의 상태를 표현합니다.
- 소품 16개는 운반물, 투입·배출구, 마력 장치, 윈치, 인부와 방 장식을 포함합니다.
- 수리공 16프레임은 네 방향마다 대기, 걷기 두 프레임, 운반 자세를 제공합니다.
- 벽 장식과 소품 16개는 석관, 촛대, 화로, 펌프, 현수막, 등불, 공구 걸이 등을 표현합니다.
- 1번 정비실에는 바닥·윗돌·벽 앞면·기둥 모서리·암석·모루 받침 9개와 함정·출구·레버·부품·벽 장식 12개를 따로 제작했습니다. 벽 윤곽과 등불 조명은 [Dungeon and Puzzles의 플레이 화면](https://nekolyst.com/games/dungeon-and-puzzles/)을 참고했습니다.
- 2~8번 방에는 새 지형 45개와 병사·발판·문·마력 장치·방 장식 36개를 적용합니다. 함정·레버·출구·수리 부품은 1번 방과 동일한 그래픽을 씁니다.

거울의 반사면과 화살표는 생성한 회전대 위에 현재 반사 각도로 그립니다. [원화 프롬프트](source/prompts.json)에 각 시트의 셀 순서와 수리공 참조를 기록했습니다.

장치 개편은 `device_mechanisms`, `device_fixtures`, `device_magic`, `device_recording` 시트에서 가져옵니다. 마력 수신기는 연결되면 밝은 수정이 차오릅니다. 발자국이 새겨진 기록 발판은 기록 중 주황색 표시등이 켜지고, 재생 문양에는 모래시계가 보입니다. 장치 도감도 탑다운 플레이 중에는 같은 스프라이트를 사용합니다. [장치 개편 프롬프트](source/device_refresh_prompts.json).

`device_gates` 시트는 연결문의 고정 석재 기둥과 움직이는 철제 문짝을 담습니다. 문짝이 기둥으로 들어가면 가운데 바닥이 드러납니다. 두 방향 모두 문짝은 문틀의 축을 따릅니다.

`node tools/art/build-topdown-v2.mjs`로 원화에서 아틀라스와 `manifest.json`을 다시 만들 수 있습니다. 기존 아트 제작용 Sharp 패키지를 사용합니다.
