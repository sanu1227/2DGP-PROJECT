# 수리공 걷기·멈춤·한숨 36포즈

기존 청록 후드 수리공을 참조해 내장 `image_gen`으로 만든 투명 PNG다. 이전 `comic_motion_v1` 원본과 포즈는 보존한다. 배경·용사·해골·마왕·숨 효과는 기존 팩을 사용한다.

- 00~11: 낮게 발을 끄는 걷기 12포즈. `sources/walk-refined.png`.
- 12~17: 마지막 발을 모으는 감속·멈춤 6포즈. `sources/settle.png` 앞부분.
- 18~23: 눈을 감고 어깨를 올리는 들숨 6포즈. 같은 원본 뒷부분.
- 24~35: 입을 벌려 내쉬고 고개·어깨를 떨어뜨린 뒤 지친 자세로 마치는 12포즈. `sources/sigh.png`.

전체 생성 프롬프트는 `prompts.json`, 걷기 수정 프롬프트는 `walk-refinement.json`에 있다. 최초 걷기 시트 `sources/walk.png`도 보존한다. 런타임에는 선택한 시트에서 분리한 `sprites/worker_smooth_00.png`~`35.png`를 사용한다.

`node tools/art/build-worker-smooth.mjs`로 다시 패키징한다. 투명 배경·셀 경계·캔버스 여백·36개 포즈의 고유성을 검사하고 SHA-256을 기록한다. 발과 공구함의 바닥은 y=344에 정렬한다. 시트마다 한 배율만 적용해 한숨 중 상체가 낮아지는 차이를 보존하며, 걷기/멈춤과 들숨/날숨 경계의 대응 자세로 시트 사이 크기를 맞춘다.

게임에서는 0.25초부터 걷고, 2.25~2.85초에 마지막 발을 모으며 감속한다. 2.85~3.45초 들숨, 3.45~4.65초 한숨 뒤 마지막 자세를 유지한다. 걸음의 포즈는 이동 거리에 맞춰 진행하며, 몸 전체를 따로 위아래로 흔들거나 늘리지 않는다. 위치와 숨 효과는 게임의 매 렌더링 시점에 계산한다.
