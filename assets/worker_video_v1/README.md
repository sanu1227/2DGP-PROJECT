# 수리공 걷기·한숨 첫 영상

`worker_trudge_sigh.mp4`는 기존 만화의 수리공 컷으로 만든 Wan 2.2 TI2V 5B 첫 샘플이다. 게임에는 아직 연결하지 않았다.

- 크기: 640×480
- 길이: 정확히 4초
- 프레임: 24fps, 총 96프레임
- 형식: MP4 / H.264, 무음
- 시드: 2026111101
- 생성 환경: RTX 4060 8GB, FP8 실행, 20 steps
- ComfyUI 실행 시간: 약 19분 2초. 당시 다른 프로그램을 종료하지 않았으며 시스템 메모리 여유가 적었다. 일반적인 성능 벤치마크로 사용하지 않는다.

## 검토

전체 프레임을 디코딩해 프레임 수, 시간 간격, 길이와 96개 프레임의 서로 다른 픽셀 해시를 확인했다. 수치는 `verification.json`에 있다.

0초부터 약 0.5초 사이에 발을 짧게 옮기고 자세를 고친다. 이후 피곤한 표정으로 고개를 숙이고, 약 3.5초에 입을 크게 벌리며 커다란 흰 숨 효과를 낸다. 초기 그림의 수리공, 청록색 후드, 고글, 공구함과 해골 구도는 유지된다.

첫 시안의 한계도 있다. 걷기가 짧으며, 긴 보행보다는 멈춘 뒤 한숨을 쉬는 동작이 중심이다. 후반 숨 효과는 머리 위까지 크게 나타나며, 소품과 배경 선에 일부 변화가 있다. 다음 버전에서 보행 시간과 숨 효과의 위치를 조정할 수 있다.

## 파일

- `input.png`: 기존 만화에서 잘라낸 입력 컷
- `workflow_api.json`: 실제 제출한 ComfyUI API 워크플로
- `generation.json`: 입력 해시, 시드, 설정, 실행 상태
- `history.json`: ComfyUI 실행 결과
- `verification.json`: 실제 MP4 전체 디코딩 검사
- `contact_sheet.jpg`: 9개 시점의 검토용 이미지
