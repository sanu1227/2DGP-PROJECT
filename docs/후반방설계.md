# 7·8번 방: 보물창고와 왕좌실

> 2026-11-13 갱신: 벨트는 제거되었으며 현재 4~8번 배치·규칙은 [새 기믹 배치 초안](새기믹배치초안.md)을 따른다. 새 방은 완주만 검증했고 행동 제한은 무제한이다. 아래 이전 배치·최소 행동·벨트 설명은 제작 당시 기록이다.

2026-11-11 구현. 두 방은 12×12 격자이며 기존 복구·운반·되돌리기 규칙을 조합한다. 최소 행동+2회 제한을 적용한다. 타이틀과 플레이 중 키보드 윗줄 `7`, `8`로 바로 입장할 수 있다.

## 7번 — 봉인된 보물창고

청록 석재와 황동 테두리, 금화와 금고 장식으로 입구 보관실·중앙 작업실·안쪽 금고를 구분한다. 안쪽 작업실에는 녹색 러너를 깔았다.

- 목표: 함정 1개, 병사 1개 복구 후 안쪽 출구 복귀.
- 장치: 문 2개, 발판 2개, 투입구 1개.
- 핵심 판단: 뼈와 부품을 문의 추로 사용한 뒤 복구 재료로 회수하는 순서.
- 최소 59회, 제한 61회.

입구의 뼈를 투입구 `(3,2)`로 보내 발판 `(6,2)`를 누르면 첫 문 `(4,4)`이 열린다. 중앙으로 들어온 뒤에는 이 뼈를 회수해도 안쪽 출구로 복귀할 수 있다. 부품을 두 번째 발판 `(6,6)`에 두어 문 `(8,7)`을 유지하고, 금고 안의 나머지 뼈를 회수한다. 초소 `(9,7)`를 채우고 중앙으로 돌아온 뒤 부품을 회수해 함정 `(6,5)`에 설치한다.

함정을 일찍 가동하면 북쪽 작업실로 돌아갈 수 없다. 초소에서 금고 쪽으로 잘못 나가면 출구 방향이 막히므로 되돌려야 한다. 문을 두 개 놓은 이유는 독립적인 개폐와 재료의 임시 용도를 함께 판단하게 하기 위해서다.

## 8번 — 마왕의 왕좌를 복구하라

흑요석과 붉은 러너를 사용하고, 뒤쪽 왕좌를 깃발과 화로로 둘러싼다. 중앙 작업 통로에서 좌우 복구 구역으로 갈라지며, 중앙 초소는 왕좌 쪽 작업 구역을 봉쇄한다.

- 목표: 함정 2개, 병사 1개 복구 후 출구 복귀.
- 장치: 문 2개, 발판 2개, 투입구 1개, 굽은 벨트 4칸.
- 핵심 판단: 부품 하나로 문을 유지하는 동안 다른 부품과 뼈를 회수하고, 북쪽 작업을 끝낸 뒤 중앙 초소를 배치하는 순서.
- 최소 75회, 제한 77회.

입구 투입구 `(3,9)`에서 뼈를 발판 `(5,8)`으로 보내 왕좌실 문 `(4,9)`을 연다. 중앙 부품을 벨트에 놓으면 먼 발판 `(9,2)`까지 운반되어 동쪽 문 `(7,6)`이 열린다. 동쪽 부품으로 함정 `(8,6)`을 설치하고 돌아온 뒤, 발판의 부품을 회수해 서쪽 함정 `(4,4)`에 사용한다. 서쪽 뼈까지 회수해 병사를 조립하고 중앙 초소 `(6,5)`를 채운 뒤, 남쪽으로 이탈해 마지막 레버를 가동한다.

초소를 일찍 채우면 벨트 발판에 남은 부품을 회수할 수 없다. 이 실패 상태와 되돌리기로 회복되는 상태를 자동 검사한다. 벨트는 먼 발판까지의 왕복을 실제로 줄이며, 벨트에 물건을 놓지 않는 풀이로는 77회 안에 완료할 수 없다.

## 신규 에셋과 표시

내장 `image_gen`으로 두 테마의 아틀라스를 생성했다. 각 팩에는 바닥 4종, 낮은 벽 4종, 소품 8종이 있다. 32종의 개별 256×256 RGBA PNG와 아틀라스, 원본, 전체 프롬프트, 검사 결과를 저장소에 보관한다.

- [보물창고 팩과 생성 프롬프트](../assets/map_pack_v1/treasury/source/spec.json)
- [보스방 팩과 생성 프롬프트](../assets/map_pack_v1/boss/source/spec.json)
- [제작·재생성 안내](../assets/map_pack_v1/README.md)

현재 두 방에는 새 바닥과 소품을 배치했다. 높은 외곽 벽은 기존 서고·제련소 팩을 사용한다. 새 낮은 벽 8종은 팩에 포함된 추가 배치용 변형이다. 모든 장식은 통행 불가 벽칸에 배치한다. 왕좌는 장식이며 충돌·복구 조건은 지도에 명시한 장치로 결정된다. 8번의 인접한 발판 이름표는 화면 여백을 따로 두어 겹침을 줄였다.

## 검증과 실행

```powershell
python main.py --stage 7
python main.py --stage 8
python main.py --check
python -m unittest discover -v
python tools/solve_levels.py --stage 7 8 --check --check-mechanics
```

단위 검사 69개를 통과했다. 실제 규칙을 탐색해 최소 행동을 확인했고, 7번은 뼈 전송과 발판에 물건 놓기, 8번은 뼈 전송과 벨트에 물건 놓기를 각각 금지하면 제한 내 풀이가 없음을 확인했다. 전체 결과는 [탐색 보고서](balance-report.json)에 있다.

창 없는 SDL 소프트웨어 렌더러에서 여덟 방 완료, 방 전환, 타이틀의 1~8 단축키, 튜토리얼, 클릭 표식, 되돌리기, 재시작을 확인했다. 전체 상호작용 상태 230개와 마지막 이름표 조정 후 새 방 상태 83개를 검사했다. 새 에셋의 투명도·여백·잘림 검사와 두 방 시작 화면 및 보스방 완료 화면 검토를 완료했다. 실제 모니터의 물리 입력과 사람의 초회 난이도는 아직 검증하지 않았다.
