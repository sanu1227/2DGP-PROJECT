# 해골 인부 개선 제안

2026-11-13. **설계 제안이며 아직 게임 규칙에 적용하지 않았다.** 현재 7·8번은 기존 윈치 배치·회수 규칙을 유지한다.

## 현재의 문제

해골을 윈치에 놓으면 문이 열리고, 회수하면 닫힌다. 입력과 결과가 발판에 물건을 놓는 행동과 거의 같다. 인부가 이동하거나 도와주는 모습도 없어 살아 있는 동료보다 열쇠처럼 느껴진다. 인부가 맡을 일을 고르는 판단이 부족하다.

## 추천: 자리를 맞춰 함께 미는 동료

핵심은 인부의 숫자나 대기 시간을 늘리는 것이 아니라 **수리공과 인부의 자리·방향을 맞추는 협동**이다. 일반 잔해와 구별되는 넓은 손잡이 두 개의 무거운 잔해를 추가한다.

- 일반 잔해는 지금처럼 혼자 민다. 무거운 잔해는 수리공이 뒤쪽에서 밀고 인부가 옆 칸에서 받쳐야 한 칸 이동한다. 발판에 올라가는 동작은 이번에 추가한 잔해 보간을 재사용한다.
- 조립한 인부를 작업 위치에 배치하면 스스로 서서 기다린다. 작업 가능 방향과 두 사람의 자리를 바닥 화살표·발자국으로 표시한다. 조건이 맞지 않으면 어느 자리가 비었는지 보여 주고 행동을 소모하지 않는다.
- 밀기 성공 시 두 사람이 같은 박자로 움직인다. 인부가 팔을 뻗고 잔해의 앞부분이 조금 들리는 동작으로 협동을 읽게 한다. 효과음과 몸동작만 짧게 사용하고 화면 흔들림은 필요 없다.
- 잔해가 작업 위치를 지나면 인부의 자리도 옮겨야 한다. 벽 모서리에서는 어느 방향으로 먼저 밀고, 어디에 동료가 설 공간을 남길지가 퍼즐이 된다.
- 인부는 최종 초소에 배치할 같은 해골이다. 공동 작업을 끝내기 전에 초소를 복구하면 인력이 부족해진다. 기존 Z 되돌리기로 복구할 수 있다.

처음에는 명령 메뉴 없이 **E / Space로 작업 자리 배치·회수, 방향키로 공동 밀기**를 유지한다. 규칙이 재미있다고 확인한 뒤에만 ‘따라오기·기다리기’를 추가한다. 명령 세 개를 처음부터 소개하면 운반·거울 규칙과 함께 배워야 할 양이 늘어난다.

## 여덟 방 안에서의 도입안

### 7번: 함께 밀기 한 가지에 집중

윈치 문을 공동 작업 구역으로 교체한다. 시작 구역에서 뼈 두 묶음으로 인부를 만들고, 옆쪽 받침 발자국에 배치한다. 수리공이 뒤쪽 밀기 자리에 서서 무거운 잔해를 한 칸 밀어 부품을 꺼낸다. 작업을 마친 인부를 초소에 배치한다. 실패 가능성은 ‘혼자 밀 수 없음’ 한 가지를 먼저 보여 준다.

### 8번: 빛의 경로와 협동 동선을 함께 계획

무거운 잔해가 거울 사이 광선을 가로막게 둔다. 처음에는 공동 작업으로 광로를 확보하고, 이후에는 잔해를 발판 위로 옮겨 인부가 붙잡던 문을 유지한다. 수리공은 거울을 맞추고, 인부는 마지막 작업을 끝낸 뒤 초소로 보낸다. 단순히 두 사람이 같은 발판을 번갈아 누르는 구성은 피한다.

이 배치는 세 거울이 모두 필요하고, 인부를 일찍 초소에 놓으면 작업이 끝나지 않도록 설계한다. 무거운 잔해를 미는 순서와 인부 접근 칸이 막히지 않는지는 실제 탐색기로 확인해야 한다. 현재 실행 지도와 별개인 다음 설계 단계다.

## 비교한 다른 방향

| 방식 | 새 판단 | 우려 | 우선순위 |
| --- | --- | --- | --- |
| 두 사람이 무거운 잔해 밀기 | 자리·방향·작업 순서 | 작업 칸을 명확히 보여 줘야 함 | 추천 |
| 인부 한 명에게 운반·윈치 중 하나 맡기기 | 어느 일을 맡기고 언제 바꿀지 | 자동 운반의 길찾기·막힘 규칙 추가 | 후속 확장 |
| 플레이어 두 행동 뒤 작업 완료 | 수리공 작업과 인부 작업을 맞추기 | 의미 없는 왕복으로 시간을 보내기 쉬움 | 보류 |

## 구현 전 확인할 조건

- 한 번의 공동 밀기는 행동 1회를 쓰고, 잔해·수리공·인부 위치를 한 번에 되돌린다.
- 손이 찼거나 다음 잔해 칸·두 사람의 이동 칸 중 하나가 막히면 전체 동작을 거부한다.
- 실시간 제한은 두지 않는다. 일시정지·생각하는 시간에는 아무 변화가 없다.
- 두 작업 칸과 이동 방향을 색뿐 아니라 모양으로 표시한다. 실행 전에 도착 위치를 미리 보여 준다.
- 밀기 애니메이션·발판 눌림·거울 광선 갱신이 서로 어긋나지 않게 한다.
- 7번에서 협동의 의미를 설명 없이 이해하는지 먼저 플레이로 확인한다. 이후 8번을 확정하고 최단 행동+2 제한을 다시 계산한다.
