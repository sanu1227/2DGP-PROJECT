# 퍼즐 배치와 행동횟수 규칙

> 2026-11-13 갱신: 벨트는 제거되었으며 현재 4~8번 배치·규칙은 [새 기믹 배치 초안](새기믹배치초안.md)을 따른다. 새 방은 완주만 검증했고 행동 제한은 무제한이다. 아래 이전 배치·최소 행동·벨트 설명은 제작 당시 기록이다.

2026-11-11 적용. 현재 1~8번 방은 이 문서와 `data/stages.json`을 기준으로 한다. 이전 기획서의 목표 수와 초기 행동 제한은 현재 값이 아니다.

## 설계 목표

플레이어가 짧은 경로와 작업 순서를 찾아야 통과하는 퍼즐로 만든다. 난이도는 재료 회수 순서, 운반물의 임시 용도, 복구 후 통로 차단에서 만든다. 같은 운반을 반복시키는 것만으로 난이도를 높이지 않는다.

## 배치 규칙

1. 방마다 핵심 판단을 먼저 정하고 장치를 놓는다. 새 기믹은 하나씩 소개하고, 이미 배운 기믹과 결합한다.
2. 벽과 장애물에는 경계, 구역 분리, 통로 차단, 운반 거리 절약 중 설명할 수 있는 역할이 있어야 한다. 우회만 길게 만드는 벽을 난이도 수단으로 추가하지 않는다.
3. 순서 퍼즐의 함정·초소는 실제 병목에 둔다. 복구 전에는 필요한 재료를 회수할 수 있고, 복구 후에는 그 구역에 다시 들어갈 수 없도록 구성한다.
4. 정상 풀이에서는 모든 복구를 끝낸 뒤 빈손으로 출구에 도달할 수 있어야 한다. 잘못된 순서로 스스로 길을 막은 상태는 되돌리기로 복구한다.
5. 해당 방의 핵심 장치를 생략한 풀이가 행동 제한 안에 들어오면 배치를 다시 설계한다. 장치가 이동을 절약한다면 그 절약이 실제 최소 행동 수에 반영되어야 한다.
6. 재료는 목표에 필요한 수량만 둔다. 함정마다 부품 1개, 병사마다 뼈 묶음 2개가 필요하다. 장식은 통행 불가 벽칸에 둔다.
7. 최소 풀이만 정답으로 강제하지 않는다. 같은 규칙과 행동 제한을 만족하는 다른 순서도 허용한다.

## 행동횟수 규칙

**2~8번 방의 제한 = 검증한 최소 행동 수 + 2회.** 1번 튜토리얼은 무제한이다. 2회의 여유는 짧은 왕복 한 번 또는 불필요한 내려놓기·줍기 한 번 정도다.

| 행동 | 차감 |
| --- | ---: |
| 성공한 한 칸 이동 | 1회 |
| 줍기·내려놓기·설치·뼈 납품·병사 배치·레버 가동·투입구 전송 | 각각 1회 |
| 두 번째 뼈 납품과 병사 자동 조립 | 합쳐서 1회 |
| 벨트 자동 운반·문 개폐·애니메이션 | 추가 차감 없음 |
| 벽에 부딪히거나 조건이 맞지 않는 입력·경로 미리보기·이동 취소 | 0회 |
| 되돌리기 | 직전 상태와 사용한 1회를 함께 복구 |
| 재시작 | 초기 상태와 전체 횟수 복구 |

마우스로 5칸 떨어진 바닥을 한 번 클릭해도 실제 5칸 이동에는 5회가 든다. 도착 후 상호작용은 별도다. 마지막 행동으로 출구 복귀까지 완료하면 성공한다. 횟수 소진 후에는 되돌리기와 재시작이 가능하다.

## 현재 방별 기준

| 방 | 핵심 판단 | 최소 행동 | 제한 |
| --- | --- | ---: | ---: |
| 1 | 함정 설치 후 건너가서 가동하고 출구로 복귀 | 19 | 무제한 |
| 2 | 두 보관실의 뼈 회수 후 입구 초소 배치 | 50 | 52 |
| 3 | 두 구역의 재료 회수, 북쪽 초소 배치, 마지막 함정 가동 | 67 | 69 |
| 4 | 부품으로 문 유지, 뼈 회수와 초소 배치, 부품 회수와 함정 복구 | 61 | 63 |
| 5 | 투입구로 발판을 누르고, 문을 건넌 뒤 뼈 회수 | 27 | 29 |
| 6 | 벨트로 발판 왕복 절약, 안쪽 뼈 회수, 초소 배치 후 귀환 | 63 | 65 |
| 7 | 이중 금고문을 뼈·부품으로 유지하고 재료를 회수해 복구 | 59 | 61 |
| 8 | 입구 봉인 해제, 벨트 운반, 양쪽 함정 복구 후 중앙 초소 배치 | 75 | 77 |

행동 수는 방의 길이를 나타내며 난이도 순위가 아니다. 5번처럼 새 장치를 소개하는 방은 짧게 구성한다.

3번은 병사 목표를 2개에서 1개로 줄였다. 함정 2개는 유지하며 뼈를 두 구역에 나누어 두었다. 4번은 함정 `(3,4)`와 초소 `(5,4)`를 보관실의 유일한 진입로에 놓았다. 6번은 발판 `(5,1)`에 닿는 굽은 벨트와 안쪽 뼈 `(8,8)`를 두고, 초소 `(7,6)`와 함정 `(5,4)`이 각각 안쪽 구역과 문 앞 통로를 차단하도록 했다. 이전의 선택적인 병사 운반 벨트는 제거했다.

## 배치를 변경할 때

1. 방의 핵심 판단과 각 장애물의 목적을 기록한다.
2. 지도와 장치 연결, 벽 장식, 재료 수를 함께 확인한다.
3. `python main.py --check`와 관련 단위 검사를 실행한다.
4. `python tools/solve_levels.py --stage N --output <결과.json>`으로 최소 행동을 구한다. 탐색 상한에 도달하면 최소 행동이 증명된 것으로 취급하지 않는다.
5. `tests/solutions.py`에 검증된 풀이와 최소 행동 수를 반영하고 `action_limit`을 최소+2로 맞춘다.
6. 아래 검사로 최소 행동과 핵심 장치 필요성을 재검증한다. 장치를 생략해도 제한 안에 완료된다면 배치부터 수정한다.

```powershell
python tools/solve_levels.py --check --check-mechanics --output docs/balance-report.json
python -m unittest discover -v
```

탐색기는 실제 `Game.act`의 이동·상호작용·내려놓기를 모두 탐색한다. 문과 복구물의 차단을 완화한 운반 거리 하한을 A*에 사용한다. 하한과 최단 비용은 작은 함정·발판·벨트·투입구 방의 전체 상태 그래프와 독립적으로 대조한다. 게임 실행 중에는 탐색기를 호출하지 않는다.

현재 검사에서는 여덟 방의 최소 행동을 확인했고, 4번 발판에 물건 놓기·5번 뼈 전송·6번 벨트에 물건 놓기를 각각 금지하면 제한 내 완료할 수 없음을 확인했다. 7번은 투입구와 발판, 8번은 투입구와 벨트를 각각 생략한 풀이도 제한 내에 들어오지 않는다. [후반 방 설계](후반방설계.md)에 새 방의 구성과 제작 에셋을 설명한다. [탐색 보고서](balance-report.json)에 해결 행동열과 검사 대상의 SHA-256을 남겼다.

자동 검사와 창 없는 SDL 검사, 변경된 방의 화면 검토를 완료했다. 실제 사람의 초회 플레이 시간과 체감 난이도는 아직 측정하지 않았다. 후속 조정은 실패 원인이 경로 선택인지, 규칙 전달인지 구분해서 진행한다.
