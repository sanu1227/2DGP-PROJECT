## 데모 재현

저장소에서 `python main.py`를 실행한다. 타이틀 또는 플레이 중 숫자키 **1**과 **7**로 해당 방으로 이동한다. 장치 안내는 **Esc**로 건너뛸 수 있다. 화살표 키는 이동, **E**는 상호작용이다.

- **1번 방.** `→ E ↓ ↓ E ↓ → → ↑ E ↓ ← ← ←` 순서로 실행한다. 부품을 줍고, 함정을 설치하고, 레버를 당긴 뒤 출구에 도착한다. 마지막 화면에서 **복구 완료**와 **사용 행동 14회**를 보여 준다.
- **7번 방.** `↓ → ↑ ← ↓`로 기록석에 방향 세 개를 남긴다. 이어서 `→ → ↓`를 입력한다. 화면 하단의 **인부 재생 3/3**과 **통과 가능**을 보여 준다. `↓ ← ← E ↓ E`로 부품을 다음 발판에 내려놓는다.
