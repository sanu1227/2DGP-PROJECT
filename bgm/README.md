# 타이틀·플레이 배경음악

사용자가 Suno로 제작하고 이 폴더에 제공한 MP3 두 곡을 그대로 사용한다.

| 파일 | 재생 화면 | 음량 (0~128) |
| --- | --- | --- |
| `Dungeon Title Theme.mp3` | 타이틀, 게임 시작 전 조작 안내 | 48 |
| `Interlocking Gears.mp3` | 모든 플레이 방 | 40 |

`game/music.py`에서 경로와 음량을 관리한다. 실행 위치와 무관하게 저장소의 이 폴더를 찾는다. MP3를 별도 변환하거나 새 오디오 라이브러리를 설치할 필요는 없다.

- 음악은 0.5초 동안 서서히 시작한 뒤 곡 전체를 무한 반복한다.
- 방 이동, 재시작, 되돌리기는 플레이 곡을 처음부터 재생하지 않는다.
- 일시정지 메뉴와 장치 안내 중에는 플레이 곡을 계속 재생하면서 음량을 20으로 낮춘다. 메뉴를 닫으면 40으로 복원한다.
- 시작 로고와 프롤로그에는 BGM을 재생하지 않는다. 프롤로그의 기존 효과음은 독립적으로 동작한다.
- 타이틀 복귀 시 타이틀 곡을 처음부터 재생한다. 종료 시 음악을 정지하고 자원을 해제한다.
- 파일이나 오디오 장치를 사용할 수 없으면 해당 곡에 대해 한 번 경고하고 무음으로 계속 진행한다.

원본의 앞뒤 무음이나 곡의 마무리는 편집하지 않았다. 반복 경계의 자연스러움과 실제 스피커 음량은 청취 확인이 필요하다.

검사: `python -m unittest tests.test_music tests.test_story_audio` 및 `python -m tests.smoke_music`. SDL 검사는 `SDL_VIDEODRIVER=dummy`, `SDL_AUDIODRIVER=dummy`, `SDL_RENDER_DRIVER=software` 환경에서 실행하면 화면과 스피커를 사용하지 않는다.
